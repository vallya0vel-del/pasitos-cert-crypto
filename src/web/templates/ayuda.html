Ayuda y referencia

Guía de uso del sistema de certificados digitales

📋
Flujo básico
1. Carga el CSV de registros en Registros CSV.
2. Ve a Certificados → Emitir.
3. El sistema firma, genera el PDF y lo registra.
4. Descarga el documento (certificado + boleta combinados).
5. Cualquiera puede verificar el folio en /verificar.
🔑
Llaves criptográficas
La llave privada vive en keys/private_key.pem y nunca se sube a git.

Si se pierde, los certificados ya emitidos siguen siendo verificables (la llave pública está en keys/public_key.pem), pero no se podrán emitir nuevos.
⚠️
Datos personales
El archivo registros_cursos.csv contiene CURPs y nombres completos. Está excluido del repositorio git. Realiza una copia de respaldo después de cada sesión de trabajo.
🔄
Re-emisión de PDF
Si se pierde el PDF de un certificado ya registrado, usa Re-emitir en la lista de certificados. Esto regenera el PDF con la misma firma original — no crea un nuevo registro ni cambia el folio.

Formato del CSV de registros

Cada columna requerida y su formato esperado

Campo Indicación Ejemplo
Nombre Completo Apellido paterno, apellido materno, nombre(s) García López Ana María
CURP 18 caracteres. Obligatorio para emitir certificado. GALA900101MJCRZN01
Último Grado de Estudio Primaria / Secundaria / Preparatoria / Técnico Superior / Licenciatura / Posgrado Licenciatura
Institución / Guardería Nombre del centro donde labora. Si no aplica: N/A Guardería Pasitos
Cargo o Puesto Educadora / Asistente / Directora / Otro. Si no aplica: N/A Educadora
Curso Nombre exacto del curso según el catálogo Puericultura
Calificación Número de 0 a 10 con un decimal 8.5
Resultado Acreditado — calificación ≥ 7
No Acreditado — calificación < 7 		Acreditado
No. de Certificado Formato PAC-AAAA-NNNN PAC-2025-0001
Folio Verificación Formato VER-NNNN — identificador único para verificación pública VER-0001
